### 🚀 About Me

* **안녕하세요, 김도훈입니다.**
* 삶의 다양한 경험과 데이터 공부를 통하여 문제점 인식 및 도출. 데이터적인 시각에서 문제해결에 최선을 다하고 있습니다.
<br/>
* **데이터 수집부터 LLM 서비스 배포까지 파이프라인 전체를 전담할 수 있어 엔지니어링 투입 비용을 효율적으로 절감시킵니다.**
* **AI/ML 파이프라인 구축:** 웹 크롤링 및 DB 설계부터 머신러닝/딥러닝, 프롬프트 엔지니어링, LLM 파인튜닝, 멀티모달 모델 구축까지 전 과정을 검증된 성능으로 구현합니다.
* **백엔드 및 인프라 전개:** FastAPI, Linux, 클라우드 환경을 활용해 개발된 모델을 안정적인 API 서버로 구축하고 서비스 인프라에 즉시 배포합니다.
* **SW 공학 기반 개발:** 소프트웨어 공학 원칙 준수 및 화면 구현 능력을 바탕으로 단순 실험 모델이 아닌 실제 운용 가능한 제품으로 완성합니다.
* **기획·모델링·배포 간 커뮤니케이션 병목을 없애 제품 개발 주기(Lead Time)를 최소화 합니다.**
