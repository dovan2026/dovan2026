<h3 align="center">🚀 About Me</h3>

<div align="center">
  <p><b>안녕하세요, 김도훈입니다.</b></p>
  <p>➡️ 다양한 경험과 데이터 분석 역량을 바탕으로 문제의 본질을 정의하고, 데이터 관점에서 최적의 솔루션을 도출합니다.</p>
  
  <br>

  <p><b>🎯 Core Value</b></p>
  <p><i>"데이터 수집부터 LLM 서빙까지, AI 파이프라인 전체를 전담해 제품 출시 주기를 단축합니다."</i></p>

  <br>

  <p><b>1️⃣ End-to-End AI 파이프라인 구축</b><br>
  웹 크롤링 및 DB 설계부터 ML/DL 모델링, LLM 파인튜닝, 프롬프트 엔지니어링, 멀티모달 모델 구축까지 전 과정을 직접 구현합니다.</p>

  <p><b>2️⃣ 안정적인 백엔드 및 인프라 서빙</b><br>
  FastAPI, Linux, Cloud 환경을 활용해 개발된 모델을 고가용성 API 서버로 구축하고 서비스 인프라에 배포합니다.</p>

  <p><b>3️⃣ SW 공학 기반 상용 제품화</b><br>
  소프트웨어 엔지니어링 원칙과 UI 구현 역량을 바탕으로, 단순 실험실 모델을 실제 운용 가능한 상용 제품으로 완성합니다.</p>

  <p><b>4️⃣ 커뮤니케이션 병목 제로화</b><br>
  기획·모델링·배포 전 단계를 이해하여 직군 간 병목을 제거하고, 제품 개발 주기(Lead Time)와 커뮤니케이션 비용을 최소화합니다.</p>
</div>
